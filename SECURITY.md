# Security policy

Report suspected vulnerabilities privately to **contact@njoysecurity.com.au**. Include the affected repository, commit or version, impact, and safe reproduction steps.

Do not open a public issue containing a vulnerability, credentials, client information, evidence, or sensitive logs. Use sanitised examples and agree a secure transfer method before sharing sensitive material.

Maintainers should triage reports, coordinate fixes and disclosure with the reporter, and rotate any exposed credentials. Removing a secret from the current files does not remove it from Git history or revoke it.

Repository changes require an independently reviewed pull request. Security fixes should preserve client boundaries and include appropriate verification. This policy does not claim certification or that every repository is production-ready.
